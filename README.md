# Card Clash

A two-player card battle game. Place characters on your board, attack with cards, and use passives and specials to win.

**Play online:** https://mobkert.github.io/card-clash/

## Local development

```bash
npm install
npm run dev
```

## Multiplayer

Host a game and share the room code — your friend joins directly in their browser. Works from the public link; no server setup needed.
